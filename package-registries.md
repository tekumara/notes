# package registries

[aqua](https://github.com/aquaproj/aqua-registry) - sourced mostly from github releases. Strongest Windows binary coverage.
[pkgx](https://github.com/pkgxdev/pantry) - mostly builds from source and publishes to CDN, similar to the homebrew model 
[mise](https://github.com/jdx/mise/tree/main/registry) - aggregator, includues aqua, github etc.
