# jjui

To apply squash to a immutable commit, select the source with `S` and then using `alt+enter` to force apply.

For other modifications of immutable commits, search [keybindings](https://github.com/vic/jjui/blob/2bb4fff1afe318ea3260e244e97eed57dcf8c092/internal/config/default/bindings.toml#L40) for `force`.
